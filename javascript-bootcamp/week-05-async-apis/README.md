# Week 5: Async JavaScript, APIs, and Crypto Market Dashboard

## Focus

Fetch remote market data with async JavaScript, handle loading and error states, and build a dashboard that displays live or mock crypto prices.

## Build

Create the **Crypto Market Dashboard** — a UI that pulls market data from an API and presents prices, trends, or summaries.

## Topics

- Promises and `async`/`await`
- `fetch` and JSON
- HTTP status handling
- Loading, success, and error states
- Environment variables and keeping API keys private

## Done when

- The dashboard clearly shows loading while data is fetched.
- API failures display a helpful, recoverable error message.
- No secret values are committed to Git.

## Folder structure

## Run the project

Open `projects/crypto-market-dashboard/index.html` in your browser, or run a local server from that folder:

```bash
cd projects/crypto-market-dashboard
npx serve .
```
