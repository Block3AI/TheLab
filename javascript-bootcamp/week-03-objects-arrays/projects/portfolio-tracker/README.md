# Block3AI Portfolio Tracker

This Node.js project combines Week 3 skills: conditionals, objects, arrays, and functions that operate on collections.

## Files

- `index.js` runs sample portfolio scenarios.
- `portfolio.js` stores assets and provides add, remove, and summary helpers.

## Run it

From this folder, run:

```bash
node index.js
```

## Tasks

1. Review how each asset is modeled as an object in an array.
2. Add a new asset and verify the portfolio total updates.
3. Remove an asset by symbol and confirm the summary changes.
4. Explain how the data model maps to the printed output.
