# Week 3: Logic, Objects, Arrays, and Block3AI Portfolio Tracker

## Focus

Model data with objects and arrays, apply logic with conditionals and loops, and organize a portfolio tracker that reads and updates structured data.

## Build

Create the **Block3AI Portfolio Tracker** — a tool to add crypto assets, track holdings, and summarize portfolio value.

## Topics

- Conditionals, loops, and logical operators
- Objects and arrays
- Accessing and updating nested data
- Functions that operate on collections
- Separating data from presentation logic

## Done when

- You can add, update, and remove assets from a portfolio.
- Portfolio totals are calculated correctly from structured data.
- You can explain how your data model maps to the UI.
