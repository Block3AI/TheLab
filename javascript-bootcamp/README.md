# JavaScript Bootcamp

A six-week, build-first JavaScript learning path for the Block3AI Lab. Each week contains a short roadmap, practice goals, and a deliverable. Start with Week 1 and move forward only after you can explain and run what you built.

## Prerequisites

- Node.js 18 or newer
- A code editor such as Cursor
- Git and a GitHub account

Check Node is installed:

```bash
node --version
```

## Six-week roadmap

| Week | Focus | Deliverable |
| --- | --- | --- |
| 1 | JavaScript fundamentals | Command-line investment calculator |
| 2 | HTML, CSS, DOM, and forms | Block3AI Crypto Investment Calculator |
| 3 | Logic, objects, and arrays | Block3AI Portfolio Tracker |
| 4 | Map, filter, and reduce | Portfolio Tracker v2 |
| 5 | Async JavaScript and APIs | Crypto Market Dashboard |
| 6 | Debugging and React/Next.js | Block3AI Developer Dashboard |

## How to use this repository

1. Read the week’s `README.md`.
2. Complete the practice tasks before extending the project.
3. Keep notes on what worked, what broke, and what you learned.
4. Commit your work at the end of each study session.

## Start Week 1

```bash
cd week-01-fundamentals/projects/investment-calculator
node index.js
```

The project runs without installing packages. Week 1 also includes a standalone variables lesson and a crypto calculator functions example under `week-01-fundamentals/`.
