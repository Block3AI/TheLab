# Week 2: HTML, CSS, DOM, Forms, and Block3AI Crypto Investment Calculator

## Focus

Learn to structure pages with HTML, style them with CSS, interact with the DOM, and build forms that collect and validate user input.

## Build

Create the **Block3AI Crypto Investment Calculator** — a browser-based tool where users enter investment details and see coins purchased, value, profit or loss, and ROI.

### Core inputs (MVP)

- Initial investment ($)
- Asset price at buy ($)
- Asset price now or future price ($)

### Core outputs (MVP)

- Coins purchased
- Current/future value ($)
- Profit/Loss ($)
- ROI (%)

### Stretch outputs

- Annualized return (simple)
- Scenario presets (BTC / ETH)
- Break-even price

## Topics

- HTML structure and semantic elements
- CSS basics: layout, typography, and spacing
- DOM selection and manipulation
- Forms, inputs, and validation
- Event handling for user interaction

## Done when

- The calculator renders in the browser with a styled form.
- User input updates the displayed results without a page refresh.
- Invalid input shows a clear, helpful message.
