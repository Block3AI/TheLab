# Week 6: Debugging, React/Next.js Introduction, and Block3AI Developer Dashboard

## Focus

Debug JavaScript confidently, get introduced to React and Next.js, and build a Block3AI Developer Dashboard that brings together frontend skills from the bootcamp.

## Build

Create the **Block3AI Developer Dashboard** — a polished app built with React/Next.js that surfaces portfolio, market, or project data in one place.

## Topics

- Reading stack traces and using browser devtools
- `console.log`, breakpoints, and systematic debugging
- React components, props, and state
- Next.js project structure and routing basics
- Deployment and project documentation

## Done when

- You can reproduce and fix a bug using devtools or logging.
- The dashboard is built with React/Next.js components.
- The project has a README with setup instructions and a demo or deployment link.
