# Block3AI Developer Dashboard

This capstone project combines Week 6 skills: debugging, React components, and Next.js project structure.

## Setup

From this folder, create the app:

```bash
npx create-next-app@latest . --typescript --tailwind --eslint --app --no-src-dir
```

Then start the dev server:

```bash
npm run dev
```

## Build goals

- Create a dashboard layout with at least two sections, such as portfolio summary and market activity.
- Use React components with props and state.
- Handle loading, empty, and error states.
- Document setup steps and add a screenshot or deployment link.

## Suggested structure

```text
developer-dashboard/
├── app/
│   ├── page.tsx
│   └── layout.tsx
├── components/
│   ├── PortfolioSummary.tsx
│   └── MarketPanel.tsx
└── README.md
```

## Tasks

1. Scaffold the Next.js app and confirm it runs locally.
2. Split the UI into reusable components.
3. Practice debugging with browser devtools or `console.log`.
4. Publish a demo or document how to run the project locally.
