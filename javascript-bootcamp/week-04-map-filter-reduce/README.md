# Week 4: Map, Filter, Reduce, and Portfolio Tracker v2

## Focus

Transform and summarize collections with `map`, `filter`, and `reduce`, then refactor the Portfolio Tracker to use these patterns.

## Build

Ship **Portfolio Tracker v2** — an improved version that filters assets, maps holdings to summaries, and reduces data into totals and reports.

## Topics

- `map`, `filter`, `reduce`, and `find`
- Chaining array methods
- Immutable data transformations
- Refactoring imperative loops to declarative patterns
- Module organization for data utilities

## Done when

- Portfolio operations use `map`, `filter`, and/or `reduce` instead of manual loops where appropriate.
- You can filter assets by criteria and compute aggregate totals.
- The refactored code is easier to read and extend than v1.
