# Portfolio Tracker v2

This Node.js project refactors the Week 3 portfolio tracker using `map`, `filter`, and `reduce`.

## Files

- `index.js` runs filtered and summarized portfolio scenarios.
- `portfolio-utils.js` transforms portfolio data with array methods.

## Run it

From this folder, run:

```bash
node index.js
```

## Tasks

1. Replace any remaining loops with `map`, `filter`, or `reduce` where it improves clarity.
2. Add a filter for assets above a minimum value.
3. Use `reduce` to compute total value and average asset price.
