# Week 1 - Lesson 1: Variables, Data Types & Strings

## Overview

This exercise introduces the JavaScript fundamentals of:

- Variables (`let` and `const`)
- Primitive data types
- Strings
- Booleans
- Numbers
- String interpolation using template literals

The program simulates a simple cryptocurrency wallet by storing wallet information in variables and printing a formatted wallet summary to the console.

---

## Concepts Practiced

- Declaring variables
- Assigning different data types
- Boolean values
- String interpolation with template literals
- Updating variable values
- Running JavaScript with Node.js

---

## Variables Used

```javascript
let crypto = "ETH";
let walletLabel = "Trading Wallet";
let cryptoAmount = 3;
let cryptoPrice = 3800;
let isActive = false;
```

---

## Expected Output

```text
Trading Wallet: 3 ETH at $3,800 each. Active: false.
```

---

## Running the Program

From the project directory, run:

```bash
node index.js
```

After making changes to any variable, save the file and rerun the command.

By completing this exercise I practiced:
